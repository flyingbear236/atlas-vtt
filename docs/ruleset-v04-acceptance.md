## Ограничения

- §10 оставляет за пределами v0.4 автоматический вызов действий, спасброски и урон по результату попадания, понятия врага и союзника, селекторы эффектов по маскам и тегам, длительность, преимущество, помеху, перебросы и произвольные цепочки событий.
- Для `select(object)` сервер предлагает экземпляры предметов из инвентарей доступных для управления персонажей. Самостоятельные объекты сцены вне инвентаря в выборе цели не участвуют.
- Журнал показывает все серверные номиналы. 3D использует номиналы и предел по количеству кубиков существующего рендерера. При других номиналах доступен текстовый результат.
- Изменения закрытых ресурсов цели доступны через лист только её владельцу и ведущему. Игроки видят публичный итог действия и те индикаторы ресурсов, которые ведущий включил на сцене.
